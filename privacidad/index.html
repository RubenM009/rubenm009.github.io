Privacidad

Esta aplicación es de uso personal. No recopila, guarda ni comparte datos de ningún otro usuario. Solo administra las cuentas de YouTube, TikTok, Instagram y Facebook de su propio dueño, para publicar sus vídeos.

Las llaves de acceso que conceden esas plataformas se guardan en un servidor privado del dueño y no se comparten con nadie. Se pueden revocar en cualquier momento desde la configuración de cada plataforma.

Esta web no usa cookies ni analítica, y no envía a ningún sitio lo que se abre en ella.

YouTube

Esta aplicación usa los Servicios de API de YouTube. Al usarla se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

Con el permiso que da el dueño del canal, la aplicación: sube sus vídeos con su título, descripción y etiquetas; lee el nombre del canal; y lee las estadísticas de sus propios vídeos (vistas, me gusta, comentarios y retención) para saber qué vídeos funcionan mejor. No accede a datos de otros canales ni de otras personas.

Esos datos se guardan solo en el servidor privado del dueño, no se venden ni se comparten con nadie, y se borran en un máximo de 7 días si se retira el permiso. El permiso se puede retirar en cualquier momento desde la página de permisos de seguridad de Google.

Privacy Policy

This app is for personal use. It does not collect, store or share data from any other user. It only manages its owner's own YouTube, TikTok, Instagram and Facebook accounts in order to publish the owner's videos.

The access tokens granted by those platforms are stored on the owner's private server and are never shared. They can be revoked at any time from each platform's settings.

This website uses no cookies or analytics and sends nothing it displays anywhere.

YouTube

This app uses YouTube API Services. By using it, the YouTube Terms of Service and the Google Privacy Policy apply.

With the channel owner's authorization, the app: uploads the owner's videos with their title, description and tags; reads the channel name; and reads statistics of the owner's own videos (views, likes, comments and audience retention) to learn which videos perform better. It does not access data from other channels or other people.

That data is stored only on the owner's private server, is never sold or shared, and is deleted within 7 days if the authorization is revoked. Access can be revoked at any time from the Google security settings page.
